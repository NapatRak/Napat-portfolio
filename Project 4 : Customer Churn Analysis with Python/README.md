โปรเจคนี้จะทำการวิเคราะห์ข้อมูลเกี่ยวกับการยกเลิกการใช้บริการของลูกค้า (Customer Churn) ของบริษัทคมนาคมแห่งหนึ่งโดยการใช้เครื่องมือ Google Colab เพื่อเขียนโปรแกรมภาษา Python สำหรับการวิเคราะห์ข้อมูล
โดยจะทำ 2 ส่วนคือสรุปและอธิบายข้อมูลเบื้องต้นและทดสอบสมมติฐานทางสถิติเพื่อหาปัจจัยที่มีความเกี่ยวข้อต่อการ Churn อย่างมีนัยสำคัญทางสถิติ

ตัวแปรเป้าหมายที่จะศึกษาคือ Churn โดยจะมีปัจจัยต่างๆที่จะศึกษามีหลายตัวแปรไม่ว่าจะเป็น
ด้านพฤติกรรมการใช้งานของลูกค้า , ค่าบริการ , การโทรสอบถามฝ่ายบริการของลูกค้า , อายุบัญชีของลูกค้า และรวมไปถึงด้านการใช้แพ็กเกจต่างๆด้วย
